# Claude Code Configuration

This is a corpus comparison project using Python.

## Project Structure
- Python project with pyproject.toml and uv.lock
- Data analysis and NLP focused with libraries like NLTK, scikit-learn, pandas
- Jupyter notebooks in src/notebooks/

## Commands
- Test: `python -m pytest` (if tests exist)
- Lint: `ruff check .` (if ruff is configured)
- Format: `ruff format .` (if ruff is configured)

## Development
- Python 3.10+
- Virtual environment in .venv/
- Dependencies managed with uv

## Notes
- This appears to be a research/analysis project for comparing text corpora
- Uses statistical analysis libraries (scipy, statsmodels)
